# 1st-project
education project for INRTU
Я - начинающий разработчик, мне интересна сфера нейросетей, а в особенности neural language processing. Поэтому в качестве темы своего первого проекта я выбрал Интеллектуальный менеджер задач, написанный на собственном фреймворке, тестовое название - TaskFlow. В отличие от обычных менеджеров задач, в которых нужно самостоятельно заполнять, дату, время, категорию и подзадачи, для Taskflow будет достаточно описание намерений на естественном языке в свободной форме, после чего программа самостоятельно определит все параметры.
